# AI 微站客户演示 V3

## 文件说明

- `ai-website-agent-prototype-v3-demo.html`：AI 微站管理端完整演示。
- `ai-website-published-site-v1.html`：发布后的完整公开微站。

两个 HTML 文件需要放在同一目录。管理端中的“预览”“查看公开微站”和发布成功后的按钮会打开公开微站。

## 推荐演示路线

1. 打开管理端，进入“AI 建站助理”，介绍“AI 自动建站、人工微调”的第一原则。
2. 点击顶部“预览”，打开发布后的完整公开微站。
3. 在公开微站依次演示：首页、产品、解决方案、客户案例、洞察、关于我们和联系我们。
4. 进入 Knowledge Hub 产品详情页和华东智造客户案例详情页。
5. 点击任意“预约演示”，提交公开线索表单。
6. 打开右下角 AI 产品助手，输入“私有化部署”“权限如何控制”或“制造业案例”。
7. 演示网站搜索、产品能力切换、解决方案筛选和案例筛选。
8. 缩小浏览器窗口，演示移动端响应式导航和页面布局。
9. 回到管理端“域名与发布”，点击“查看公开微站”。
10. 模拟确认发布，发布成功后顶部按钮会变成“查看已发布站点”。
