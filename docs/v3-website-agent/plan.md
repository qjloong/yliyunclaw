AI微站与推广助手

这是你当前最值得押注的AI方向，因为它同时具备产品差异化、品牌传播和自然获客能力。

## 1. 产品定位

> 用户选择云盘里的文件，AI自动提取内容、生成页面、发布网站，并持续辅助更新和推广。

## 2. MVP功能

* 从文件夹、PDF、Word、图片生成网站
* AI提取企业、产品、案例、联系方式
* 选择网站模板
* 自动生成栏目和页面
* 可视化修改文字和图片
* 一键发布
* 绑定二级域名
* 表单收集客户线索
* 网站访问统计
* 来源渠道统计
* 网站内容回存网盘
* 文件更新后提醒同步网站

第一版只支持三类网站：


1. 企业产品介绍站
2. 项目资料展示站
3. 营销落地页

## 3. 推广助手

网站生成后，继续生成：

* 微信公众号文案
* 朋友圈文案
* 短视频口播稿
* 产品海报文案
* SEO标题与关键词
* 邮件推广内容
* 不同平台的分享链接

这样可以形成闭环：

> 企业资料 → AI微站 → 多平台内容 → 外部访问 → 商机线索 → 数据回流。

## 4. 收费方式

* 免费版：1个站点，带一粒云品牌
* 专业版：多个站点、自定义品牌
* 企业版：独立域名、表单、访问分析
* AI用量包：内容生成、图片生成、批量更新
* 模板增购：行业模板、活动模板、产品模板
