☁ 云盘集成说明

存储层：所有文件实际存储于云盘（通过 MCP 接口对接）。MateClaw 不存储文件本身，仅管理文件的引用元数据、分类标签和关系链路。

MateClaw 管理的元数据：文件路径（云盘路径）、类型、大小、版本、关联项目/任务/里程碑、母版-派生关系、最后同步时间。

PM Robot 自动能力：① 扫描云盘新增文件自动归类；② 检测下游资料是否引用过期母版版本；③ 母版更新后自动通知所有下游资料负责人；④ 生成复用建议（如"客户方案中 78% 内容来自母版，建议先更新母版再派生"）。

权限：读取云盘需 Workspace 级授权；写操作（创建/修改文件）需用户确认。PM Robot 不可在未经授权的情况下修改云盘文件。
