## 《Agent Harness》

目的：解析 Claude Code Agent Harness 的系统架构与设计心智模型，提炼可迁移原则，而非使用教程或 Prompt 技巧。
核心概念：
Agent Harness：智能体的运行时框架，承载对话循环、工具系统、权限管线等核心模块。
心智模型：理解 Agent 如何处理任务、管理上下文、协作子智能体。

## 二、逐章要点摘要

### 第一部分：基础篇

-智能体编程的新范式
Agent 不是单一函数，而是事件驱动、状态管理的系统。
强调 Harness 作为智能体的底层支撑。
核心心智模型：对话循环 + 工具调用 + 权限管控。

-对话循环 — Agent 的心跳
循环驱动 Agent 行为和决策。
状态机控制任务流、处理异常和重试。
支持多步推理和延迟执行。

-工具系统 — Agent 的双手
工具定义统一协议、注册机制。
可并行调用、支持异步执行。
设计模式：工厂模式 + 插件化。

-权限管线 — Agent 的护栏
四阶段权限检查：输入验证 → 权限评估 → 执行许可 → 审计。
保证安全边界，避免滥用和错误操作。

### 第二部分：核心系统篇

-设置与配置
分层配置体系（全局 → 会话 → 工具）。
支持功能开关和安全策略配置。

-记忆系统
长短期记忆分层存储。
索引机制用于快速检索。
支持跨会话上下文记忆。

-上下文管理
控制 token 预算。
上下文压缩策略。
优先级队列管理任务信息。

-钩子系统
生命周期钩子（启动、执行前、执行后、关闭）。
事件驱动扩展接口，便于外部插件集成。

### 第三部分：高级模式篇

-子智能体与 Fork 模式
子智能体继承父上下文，实现并行任务处理。
Fork 模式用于多线程或多任务分支。

-协调器模式
多代理编排与任务分配。
支持协作式解决复杂任务。

-技能系统与插件架构
Skill 协议定义，插件动态加载。
支持扩展行为、第三方工具调用。

-MCP 集成与外部协议
允许 Agent 与外部系统交互。
桥接协议确保数据和命令安全。

### 第四部分：工程实践篇

- 流式架构与性能优化
并行预取、惰性加载。
提升启动速度和运行效率。

- Plan 模式与结构化工作流
先计划、再执行。
任务拆解、阶段性反馈和修正。

- 构建 Agent Harness
融合循环、工具、权限、记忆和插件体系。
实现完整可运行智能体框架。

## 三、关键架构图概念提炼

-Agent Harness 总体架构
对话循环 → 智能体的核心调度
工具系统 → 执行单元、行为接口
权限管线 → 安全约束与策略
记忆系统 → 上下文与历史存储
钩子与插件 → 可扩展接口

-子智能体 Fork 流程图
父 Agent 状态 → Fork → 子 Agent 独立循环 → 结果回归父 Agent

-任务协调器模式
任务分解 → 多智能体并行执行 → 汇总结果 → 更新主上下文

-上下文管理与 Token 优化
输入压缩 → 优先级筛选 → 历史记忆裁剪 → 预算控制

-插件/技能加载流程
插件注册 → 生命周期钩子绑定 → 动态加载 → 事件触发执行
